# EventSphere – Event Discovery and Registration Website

## Project Overview
EventSphere is a web-based event discovery and registration platform. It allows users to explore events, view event details, register for events, and contact the EventSphere team.

The project also includes an admin section for managing website information.

## Features

### Client Side
- Home page
- Event listing and event details
- Event registration form
- Image gallery
- About Us page
- Contact form with JavaScript validation

### Admin Side
- Admin dashboard
- Event and registration management pages
- Messages management

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` – Main homepage
- `client/` – Client-side pages
- `admin/` – Admin-side pages
- `css/` – Stylesheets
- `js/` – JavaScript validation files

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.

## Validation
JavaScript validation is implemented for the registration and contact forms.
